# AIChatApp — OpenRouter + Codemagic

## GitHub

Repository: helloanhem07/appios

## Codemagic

Connect this repository to Codemagic and run the `ios-workflow` workflow.

The workflow generates the Xcode project with XcodeGen and builds the iOS app.

## OpenRouter API key

The app asks for the OpenRouter API key on first launch and stores it in the iOS Keychain. Do not commit an API key to this repository.
